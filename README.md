## À propos

**ANTSANIONY Feno Hasina**, développeur web et mobile spécialisé dans les outils numériques pour l'éducation : gestion scolaire, suivi des élèves, paiements, applications Windows et Android. Je conçois des solutions simples et accessibles pour les écoles à Madagascar, et je réalise aussi des supports de design graphique (flyers, affiches, identité visuelle).
